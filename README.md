# CUTROOM 下载与更新

CUTROOM 是面向视频制作同事的本地 Windows 工具。此包提供程序、操作手册和版本说明；开发源码与开发记录在独立私有仓库维护。

## 获取与更新

从[公开发行页](https://github.com/qnwhageqlavs-jpg/cutroom-releases/releases)下载最新的 `CUTROOM-v<版本号>-windows-x64.zip`，解压到固定目录（例如 `D:\CUTROOM`），双击 **安装CUTROOM.bat**，安装完成后用 **启动CUTROOM.bat** 打开。首次安装需要联网获取 Python、Node.js、FFmpeg 及依赖。不要下载 GitHub 自动生成的 Source code。后续双击安装目录内的 **产品更新升级.bat** 检查更新，无需 GitHub 账号。

升级前保存页面草稿并等待所有任务结束；退出 Agent 客户端并重启电脑后，先运行升级入口。只关闭网页不会停止后台。升级工具保留任务、素材、账号配置与原启动路径；遇到不兼容或校验失败会停止并说明下一步。历史失败或结果未知的调用不会在升级后自动重跑；文件缺失等未解决问题会在维护盘点中列出。不要手动把 ZIP 覆盖到旧目录。旧版本没有升级入口时，运行新解压包中的升级入口并选择原安装目录。当前快捷升级要求依赖和数据库结构兼容，程序文件没有本地修改；不符合时停止并交维护人员处理。

## 使用与反馈

任务和素材保存在使用者自己的电脑上；模型服务使用使用者自己的有效账号，可能产生费用。程序不会因下载或升级自动上传任务、调用模型或发布视频。

遇到问题可从网页导出报错日志，网页不可用时运行 **导出报错日志.bat**，将日志包和操作步骤交给维护人员。不要在公开 Issues 上传任务库、密钥、原片或客户资料。

公开提供程序下载不等于开源授权。浏览器资源与打包后的程序仍可能被分析；源码仓库及其历史不会在这里公开。

数字人和信息流广告两条路线已在本机独立安装版通过真实制作、人工审片和导出验收。安装包另有改文案、换底片、配音恢复、转写修复和交付重试的定向检查；具体覆盖范围与限制见对应发行说明。
