# CUTROOM｜把文案和本地素材做成短视频

从数字人口播，或一份广告文案和一批本地素材开始，完成选镜头、配音、字幕包装、审片和导出。你可以让 CUTROOM 先推荐，再在同一工作台里预览和调整；无需用聊天助手代替产品完成日常剪辑。

## 它能帮你做什么

- **按文案初选镜头。** 使用已登记、已分析的本地视频和图片，为每段旁白推荐画面；可查看原片、取用位置，再更换或调整。推荐后由你核对是否与文案相符。
- **把数字人口播剪得更丰富。** 保留原声，在需要的位置补充实拍、图片和信息卡；没有合适补充素材时可以保留人物画面。
- **让广告文案变成有声音的短片。** 选择本片音色、试听和调整读法，再按实际配音安排镜头，支持横屏和竖屏广告。
- **集中完成字幕和包装。** 调整字幕、标题、音乐、信息卡、Logo 等，预览组合效果；把常用样式存下来重复使用。
- **改片时保留旧成果。** 修改文案、换画面、换声音或调整包装时，按页面提示重做受影响的步骤，已有成片和交付记录保留。
- **把素材留在自己的电脑上。** 本机及移动硬盘目录统一登记、搜索和预览。AI 分析前会说明发送哪些内容及费用，原片不会因登记被移动。
- **审好再交付。** 技术检查和 AI 建议帮助发现问题，你完整观看并确认后导出 MP4；封面和平台发布文字按需附带。

## 选择制作方式

| 你已经准备好 | 选择路线 | 得到什么 |
| --- | --- | --- |
| 数字人口播 MP4、对应文案、可选补充画面 | 数字人混剪 | 保留口播原声，增加字幕和补充画面的竖屏短片 |
| 广告文案、本地视频或图片、可用配音账号 | 信息流广告 | 带配音、字幕和包装的横屏或竖屏短片 |

CUTROOM 处理已有数字人口播视频，不生成数字人形象。目前交付 MP4，不提供剪映原生可编辑工程，也不自动发布到短视频平台。

本次发行：[CUTROOM v0.9.0-beta.80](https://github.com/qnwhageqlavs-jpg/cutroom-releases/releases/tag/v0.9.0-beta.80)，附可直接打开的 HTML 操作手册。

## 第一次使用：安装、准备、做一条短片

1. **下载安装包。** 在下载页的 Assets 中选择名称含 windows-x64 的 ZIP，不选 Source code。适用于 Windows 10/11 的 64 位电脑。
2. **完整解压。** 放到固定、可写的目录，例如 D:\CUTROOM。不要在压缩包窗口中直接运行。
3. **完成安装。** 保持联网，双击“安装CUTROOM.bat”，等待“安装完成”；首次安装会准备必要组件。提示失败时保留窗口，按提示处理后再试。
4. **打开工作台。** 双击“启动CUTROOM.bat”。以后也从这个入口打开，不用记网址。
5. **准备账号与素材。** 在“设置”中配置自己可用的 AI 服务，再到“镜头素材”登记本次使用的文件夹。广告还需配音服务，数字人使用已有原声。账号不清楚时请管理员协助。
6. **创建第一条视频。** 先选一条素材齐全的短片，按下方五步完成，导出后打开 MP4 检查。

模型检测、配音和 AI 分析可能产生服务费用。只使用网页即可制作视频；连接 WorkBuddy、豆包工作等助手属于可选功能。

## 五步完成制作

| 步骤 | 你需要做的事 |
| --- | --- |
| 1. 文案与声音 | 广告确认文案和音色；数字人核对原声与文案，处理识别疑点 |
| 2. 选择画面 | 查看推荐镜头，替换不合适的画面；数字人也可保留原人物画面 |
| 3. 粗剪调整 | 连续预览，检查顺序、取用位置和旁白配合，再确认画面 |
| 4. 包装与审片 | 设置字幕、标题和音乐，生成成片；完整观看，处理检查问题后确认 |
| 5. 交付导出 | 选择保存位置并导出，按需补充封面与发布文字 |

主推进按钮在步骤底部。需要看清画面时，使用工作区工具栏右侧的“展开工作区”；收起后继续原来的操作。生成期间可查看进度，关闭网页不会取消后台处理。

## 素材多时，能用得动吗？做完一条片要多久？

**素材可以集中管理，再按项目选择使用范围。** 已有本机模拟测试使用 23,000 条素材记录：在后台同时处理视频的情况下，4 路读取共 80 次素材分页查询全部在 1 秒内完成，没有查询错误。这测的是已登记素材的列表读取，不是首次扫描、分析 2 万个真实视频，也不是每台电脑的整页打开速度保证。

**目前不承诺“从创建到导出只需几分钟”。** 首次素材分析、片长、电脑速度、外部 AI 服务和人工修改次数都会影响总时间。页面会显示当前处理进度和有依据的耗时参考；已分析素材可复用，避免每条片重新分析。首次使用建议先把一条短片完整做通，再批量开展工作。

## 更新与遇到问题

- **更新：** 保存草稿、等待处理结束，按“产品更新升级.bat”的提示操作。已有任务不要通过手工覆盖旧文件夹升级；正常更新会保留任务、素材登记、配置和交付记录。
- **播放失败：** 使用播放器“播放异常？”中的重新载入；若提示文件缺失，先重连素材或返回可用的当前版本。
- **处理失败：** 看页面原因，再使用对应的继续或重试入口。配音结果未知时先找回原请求，不要连续重新生成。
- **反馈问题：** 点页面“导出报错日志”；网页打不开时使用安装目录的“导出报错日志.bat”。把日志、所在步骤和出错时间交给维护人员，不分享账号密钥。

当前为 Beta 试用版。两条制作路线已有本机独立安装、人工审片及导出记录；历史广告首次打开偏慢、偶发播放异常仍在专项排查。新电脑请先完成第一条短片验收，不能把本机结果视为所有电脑和素材都已验证。
