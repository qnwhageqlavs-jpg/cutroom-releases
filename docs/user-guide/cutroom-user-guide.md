## 连续返工与转写恢复

数字人更换不同时长的口播底片、修改文案后又改回原文，仍按当前确认输入重建转写和分镜。旧时间轴、镜头选择和补拍记录保留为历史；不能用旧版本的画面锁定或观看记录确认新版本。

“保留原件并重新转写”会同时保存受影响的原分镜与人工选择。恢复完成后从分镜推荐入口重新处理；备份或识别中断，使用本次处理的重试入口接续。已有成片与历史人工批准不会删除，重新生成的成片仍须重新审看。

信息流广告正式改稿并确认后，配音编辑保留已选音色及旧配音历史，但新稿须生成并应用新配音。若旧版本已确认改稿却提示配音上下文不一致，可重新打开配音编辑器，让产品核验相邻的正式返工记录并恢复编辑；存在未核清的生成请求时，先按请求状态处理，不能重复发起付费生成。其他来源不明或服务已变化的记录不会被强行绑定。



### 新建任务中断与选材更新

新建任务时重复点击或响应丢失后重试，同一请求会返回已创建的任务。若程序在创建中退出，重新启动会恢复创建记录；重试仍由产品正常完成。归属无法核实的文件会保留并记录诊断，不会自动删除。旧版未完成的创建请求会提示先核对任务列表，避免重复新建。

自动匹配仍优先满足内容、来源、时长与画质。在同等候选可选时，会参考实际相邻镜头的运动方向，减少连续同向镜头；方向未知不作猜测，也不会镜像或倒放素材。刷新选材保留人工镜头，无法替换的旧镜头也参与相邻判断和重复限制。此偏好不代表最终剪辑效果已由人工验收。

### 工作区展开与审片操作

粗剪、调整包装和检查成片的预览工具栏提供“展开工作区”。点击后放大当前编辑区，再点击“收起工作区”或按 Esc 返回原布局。展开审片保留播放器和观看进度，收起重复导航与检查摘要，将空间留给画面；需要重新检查或查看完整摘要时先收起工作区。有编辑弹窗时先关闭弹窗。顶部制作步骤条的常规样式保持。

检查成片底部左侧返回调整包装，右侧集中显示观看进度、必要的人工核对声明和确认成片操作。文案页的“读法与试听”与选词提示放在同一工具组。多个标签页修改同一包装方案时，旧页面会提示版本冲突；请刷新当前方案后再操作，避免覆盖另一页的新设置。


## 本地验收版 beta.29：检查成片工作台与恢复

“检查成片”沿用三栏布局：左侧按类别筛选检查问题，中间播放当前版本，右侧查看并处理选中问题。切换问题只定位播放位置；同类问题可显式勾选后批量填写共同保留原因，仍逐项保留核对记录。

生成中、暂停或失败时保留同一布局；底部左侧返回调整包装，右侧继续或重试。刷新状态、取消本次处理和导出日志集中在“处理详情”中，正常运行自动更新。有上一版时可展开对照，它不能代替本版审片。AI 检查失败与成片生成失败分别显示；完整观看与人工确认仍按本版记录核验。

分镜生成后的本地保存若失败，可用“重试处理”继续落地已生成结果。程序会检查文案、声音、模型与素材范围及文件签名；输入已变或文件损坏时会明确停止，不悄悄重新收费。首次生成分镜仍须人工确认；重复提交同一有效分镜不会清掉已有确认。

此说明针对本地验收更新，公开下载版本以下方正式发布信息为准。

包装预览点击播放后，会先准备观看记录，随后自动播放。播放到片尾后等待“已观看，可以生成成片”再确认；记录保存成功后刷新仍有效。更新页面版本前先保存正在编辑的内容；已保存的同版观看记录无需重复播放。

旧任务提示“找不到已确认文案”时，应先从同版本备份恢复，或由维护人员核对原文案哈希后恢复。配音及对应时间文件也缺失且无可用备份时，需明确同意重新生成，可能产生服务费用。新配音时长变化后，重新进入粗剪完整观看并锁定画面，再生成包装预览；旧观看与批准记录不能代替新版本确认。安装版配音使用随包提供的运行文件，无需安装 ts-node。

后台处理时保留当前工作区，用紧凑状态条展示进展；“处理详情”从右侧打开，可按 Esc 关闭。旧预览仅供对照，本次完成后需重新观看确认。正常状态自动刷新；失败、目录离线或结果待核对时，按状态条给出的操作处理。回看旧步骤时，可通过提示栏“返回当前步骤”继续制作；耗时参考按需展开。

> 左侧任务按固定列表显示，名称下方标注制作阶段和运行状态，不按状态分组。首次按当前任务顺序展示，此后已有任务不因处理、失败或完成而换位；刷新保留顺序，新任务置顶。任务中心的搜索、筛选与排序只影响中间列表。点击任务名称进入对应阶段；顶部箭头仍可折叠整个侧栏。

## 安装与每天打开

刷新时会先显示当前模块名称和加载提示，读取完成后仍停留在该页面。若提示页面未能完成加载，可点击“重新加载”；持续失败时导出报错日志。

### 首次安装

1. 打开公开下载页，无需登录 GitHub，在 **Assets** 中下载 Windows ZIP；不要下载 **Source code**。
2. 完整解压到自己可写的短路径，例如 `D:\CUTROOM`。
3. 保持联网，双击 **安装CUTROOM.bat**。看到“安装完成”前不要关闭窗口。
4. 双击 **启动CUTROOM.bat**，等待浏览器打开工作台。

需要 Windows 64 位、联网和软件安装权限。安装器会准备 Python 3.11、Node.js LTS、FFmpeg 等必要组件；无需自己写代码或逐个安装依赖。提示缺少 `winget`、权限不足或环境不完整时，保留错误信息并联系维护人员。

### 日常使用

- 每次双击同一个安装目录中的 **启动CUTROOM.bat**；不要移动整个安装目录。
- 使用启动入口打开的页面。提示“未授权”时重新运行启动入口，不要只反复刷新网址。
- 关闭浏览器不会取消正在处理的任务；再次打开后，在任务中心查看进度。
- 需要中止时，使用页面提供的“安全暂停”或取消操作。已发出的模型请求仍可能产生费用。

已有任务的用户先阅读[升级、回退和卸载](#upgrade)。原位升级保留原任务；换电脑或换目录另按维护流程迁移。

## 首次设置：账号、能力与音色

打开 **设置 → AI 服务连接** 添加供应商连接，再到 **模型与配音** 为需要的功能选择模型。每个场景点击“管理配置（数量）”查看已有模型；点击“＋ 添加模型”直接打开独立新增表单，原配置保留。保存按钮固定在底部。同一功能可保留多个配置并指定默认项。新增模型及更新配音凭据沿用“保存并检测”，可能按供应商规则计费；检测结果单独显示。没有账号或不清楚开通范围时，请负责模型服务的管理员协助。

新增豆包连接只展示新版API Key及音色目录AK/SK；只有已使用旧凭据的连接才保留兼容入口。关闭面板可保留当前页的未保存输入，刷新会丢失。**存储与清理** 查看空间、保存位置及缓存清理；先预览清理范围，再确认。

| 能力 | 什么时候需要 | 怎样选 |
| --- | --- | --- |
| 文案策划 | 使用“CUTROOM 自己规划”时，用于文案、分镜和包装建议 | 选择已开通的文本模型，填写供应商提供的准确模型名称或接入点 |
| 配音 | 信息流广告需要；数字人使用原声 | 选择已开通的配音服务，在中文音色目录中选常用声音 |
| B-roll | 本地画面不足、需要生成补充视频时 | 可选；已有合适素材时不必配置 |
| 视觉服务 | 希望分析素材画面或使用模型辅助内容检查时 | 可选；按设置页完成检测后再使用 |

### 豆包配音怎样填写

- **豆包 API Key**用于合成、试听和连接检测。
- **AK/SK**用于自动刷新音色目录，即 Access Key ID 和 Secret Access Key。
- **AppID + Access Token**属于旧版兼容，新版账号可以留空。
- 按账号实际开通情况选择配音服务版本，再从中文名称列表选择音色。新建广告任务不要求配音服务或音色；进入“文案与声音”后选择并保存本片声音。文案草稿可先独立保存；音色保存失败会单独提示，确认和配音生成前仍需选择可用声音。

**“保存并检测”会生成极短的测试语音，可能计费。** 等待结果后再操作，成功后不用重复点击。密钥由当前电脑、当前 Windows 用户的凭据管理器保存，不需要修改配置文件，也不要把密钥发到群里。

新任务只能选择检测有效的配置；超过 24 小时会提示重新检测。任务创建后保留本次选择，后来修改默认模型或常用音色不会自动改变旧任务。

如果音色目录为空、提示缺少 AK/SK 或没有权限，请先处理账号配置。详细字段和账号权限见[供应商配置说明](../operations/model-profiles-new-api.md)。

## 准备并登记镜头素材

镜头素材是实际使用的图片和视频，可以保存在本机硬盘或移动硬盘。建议把不同项目分开存放：本片专属画面放“主素材”，可跨项目使用的城市空镜、交通、办公等放“通用补充素材”。

1. 打开 **镜头素材**，登记实际文件夹，填写容易识别的名称及用途。
2. 首次添加目录后会自动开始扫描，等待完成即可。以后新增或更改文件，再点击 **检查更新**。
3. 创建任务时选择本次主素材目录，再按需勾选通用补充目录。

扫描包含本目录及各层子文件夹中的支持格式素材。扫描期间显示等待或正在扫描，按钮暂不可重复提交；完成后自动更新目录数量和下方台账，无需刷新页面。台账仍按当前任务范围和筛选条件显示。若出现“刷新扫描状态”，点击只读取原任务，不会再次提交扫描。目录扫描是登记文件，不等于完成画面内容分析。

登记不会移动或重命名原片。新增文件后再检查更新；移动硬盘盘符或目录位置变化时使用 **重新连接**，不要删除旧库后重新登记。

制作前确认素材在线、有足够可用时长，且画面方向适合本片。横版任务不要依赖竖版素材自动变成合适的横版画面。未取得使用权、含隐私或归属不清的文件先不要用于正式任务。

## 创建后按路线完成五步制作

创建任务先确定输入与素材范围，不计入制作步骤。

| 顺序 | 信息流广告 | 数字人混剪 |
| --- | --- | --- |
| 01 | 文案与配音 | 口播核对 |
| 02 | 分镜推荐 | 补充画面 |
| 03 | 粗剪调整 | 粗剪调整 |
| 04 | 包装与审片 | 包装与审片 |
| 05 | 交付导出 | 交付导出 |

点击任务中心的任务名称或“打开”，进入该任务当前阶段；已完成任务进入交付结果。点击已完成步骤可直接回看，尚未开始的步骤不可跳过。任务状态在右上角。任务侧栏保持固定列表，状态显示在任务名称下方；顶部箭头折叠整个侧栏。只有任务模块显示新建任务按钮，镜头素材、包装素材和设置仅保留折叠按钮。点击左上角 CUTROOM 返回任务中心。

### 基础准备：创建任务

点击新建视频，选择路线和素材目录。广告选择画幅，文案与本片声音在下一页确认；数字人选择已有口播MP4，保留原声，不选广告配音。网页自动使用CUTROOM规划；Agent通过MCP控制，无需在网页切换规划方式。完成预检后创建。

本地补充画面可用于两条路线。AI生成B-roll目前尚未接通工作台完整处理，不能仅靠选择生成模型就自动补齐画面。


创建前会自动检查视频是否可用、素材目录是否在线、运行组件及可用磁盘空间。通过项无需处理；“脚本运行组件”由安装包提供，不需要自行安装ts-node。文案在下一步填写和确认，创建页不把正常待填状态列为提醒。

### 01 文案与配音／口播核对

广告在“本片配音”选择服务与音色，可试听；保存草稿时保存本任务选择，刷新保留，不影响其他任务或全局音色。文案锁定后，点击“更换本片音色”，选择音色并生成试听，确认后再应用；已有读法保留，应用后需重新检查受影响的画面和成片，旧版交付保留。生成前会明确确认本次请求次数与费用。纠正具体词句读法时才需要先选中文字，再点击“读法与试听”。旧任务中未应用的空编辑记录会对齐当前已确认文案，不调用模型；有未决生成请求或正式声音版本冲突时，应先核对原记录。



**数字人路线：** 填写与 MP4 口播一致的文案，播放原声核对；也可试听制作速度。确认后点击 **确认与口播一致，继续**。系统转写核对后若提示数字、否定词或漏句疑点，按时码回听：文案错了就改稿，视频错了就更换底片并重新核对。

**广告路线：** 填写最终文案，保存、通读，再点击 **确认文案，继续**。确认文案本身不会立即生成配音；进入后续规划和声音生成时，再按页面确认调用。视频时长以实际生成的配音为准。

保存草稿不等于确认。需要改已确认文案时，使用 **修改文案**；已有候选成片时先在审片页记录返工。保存前弹窗会说明需要重新完成的步骤，技术文件清单默认收起。数字人的原视频与原声不因改文字而变化，旧结果保留为历史；点击 **保存并返回文案确认** 后，确认新文案，再重新识别并核对口播。广告则按新文案重新配音和制作；实际影响以弹窗为准。

数字人文案改回曾经用过的版本，也要重新确认当前文案。若原转写已随返工归档，系统会重新排入本地识别；重复点击不会重复排队。取消识别后，只有再次明确确认文案才重新发起；失败作业仍使用页面的重试操作。若提示转写文件缺失或已变化，在口播校对区域点击 **保留原件并重新转写**。确认后，程序会把原转写文件留在任务历史中，使用当前已确认文案和原口播在本机重新识别，不调用付费模型。中断或失败时使用页面重试，原备份继续保留。恢复后重新核对口播，并重新检查受影响的分镜、粗剪与包装；旧成片和交付记录保留，但旧批准不能代替新版本确认。若原口播也发生变化，须先走“更换口播视频”重新确认，程序不会混用新视频。

### 02 分镜推荐／补充画面

数字人先在 **口播核对** 完成原声与文案核对，再进入 **补充画面**：

1. 点击 **推荐补充画面**，核对调用与费用提示。已有推荐结果时优先恢复，避免重复调用。
2. 对照每段口播选择镜头。候选来自本任务已选的本机素材库；查看素材库名称、源文件、起止时间，并播放候选片段后再应用。
3. 没有合适素材时使用 **保留人物画面**，继续显示数字人。换画面仍保留这段口播原声。
4. 选好后点击 **生成粗剪**，到下一步观看实际组合效果。

补充画面页会显示本任务已选择的素材库、文件数和实际路径。镜头素材页当前浏览的库不一定是本任务已选的库；先对照名称与路径。文件数与分析区间数不同：一个较长视频可能拆成多个区间，图片也单独计一项，分析不会增加原文件。文件名不能证明画面内容。缩略图完整显示源画面；点击查看可播放。补充素材和口播不在同一目录时，仍可在候选中选择“恢复口播原画面”。

回听疑点和改文案、更换视频都在前一步。若出现“视频和文案是否配对正确”，先核实是不是选了不同内容，不能只逐条勾选通过。补充画面页不自动联网找素材或生成视频。


素材列表中的 **已有片段** 表示该文件已有当前有效的画面观察，不代表全片已分析；**待分析** 表示尚无可用于自动内容匹配的当前观察。登记扫描建立文件目录；本机检测补齐时长、尺寸和横竖方向，并检查场景与画质。AI 内容分析识别可见内容，供分镜选材使用。

本步已有当前分镜时会直接展示；查看内容期间，后台任务状态仍会刷新。返工后点击 **生成粗剪** 会重新核验源文件，核验通过后才继续。若候选大量提示“时长不足”，先检查单个镜头是否过长，并调整镜头安排；不要仅为刷新状态重复发起 AI 推荐。

按页面发起分镜处理，检查每段文案和建议画面是否对应。素材检查未完成时先等待；若提示源文件变化，点 **查看素材变化**，核对后再同步。

有可用的已生成结果时，使用 **恢复已生成分镜**，避免重新发起模型调用。选好初步画面后点击 **生成粗剪**。素材较多时，后台完整核验可能需要数分钟；刷新只查看已有进度，可以先回任务中心。

缺少画面时点 **查看缺口处理清单**，按[缺画面的处理方法](#gaps)补齐。数字人可保留原人物画面；广告需要为每段配好真实可用的画面。

### 03 粗剪调整

编辑区采用连贯三栏面板，镜头列表和详情各自滚动，播放控制固定在画面下方。较矮窗口可向下滚动到编辑区，或点击“展开工作区”扩大画面；历史任务缺少主声时仍只能逐镜回看。

若提示视频需要兼容预览，点击“生成本片兼容预览”。系统在本机按本片选用的视频去重生成预览，复用有效缓存；完成后自动刷新，再检查并确认粗剪。预览转码不更改原素材、取用秒数或最终渲染源，也不调用 AI。处理中切换任务将停止继续排入剩余素材；已完成缓存仍可复用。

先连续播放，再逐个点击镜头，检查旁白、画面和字幕是否配合。

粗剪现在采用同屏工作区：左侧镜头列表独立滚动，中间连续预览，右侧查看当前镜头与调整操作。点击镜头、上一镜或下一镜会暂停并定位，不重建整页。小屏可点“调整镜头／镜头详情”打开侧面板；需要更大画面时点“展开工作区”，点“收起工作区”或按 Esc 返回。粗剪、调整包装和检查成片均保留此入口，展开不会代替保存、确认或审片。顶部制作步骤的样式保持原样。耗时与回看提示在底部“操作说明／回看说明”中。

每个视频镜头直接显示文件名与原片取用起止秒数；完整路径在“查看素材来源与系统建议”中；它与成片时间轴的位置分别展示。素材分析完成后，可点击 **按最新分析更新自动选材**：只更新自动推荐，保留手工替换、裁剪、排序和确认过的镜头，支持撤销、重做。画面已锁定、已有包装或成片成果、后台作业未结束时不能直接刷新，应按页面提示处理或走返工。

选材先分配精准匹配和相关画面，再用本园区未使用的已分析素材填补缺口。次级填充会说明依据和限制，通用园区画面不代表已经证明旁白中的具体设施或政策。

- **更换或增加画面**：点“更换镜头”或“后面添加镜头”，在独立素材面板中搜索并翻页查看候选。左边选素材、右边预览，关闭后保留原镜头。先选中并预览，再按替换或应用按钮确认；仅点选候选不会改片。
- **判断同向素材**：广告候选显示实际竖屏、横屏或方形、展示尺寸及“与本片同向／方向不符”，不依赖文件名中的横版、竖版。方向未知时，选中素材后点击 **检测所选素材**，仅在本机检查该素材，不调用付费 AI；每项通常约30秒—3分钟。检测结束后自动刷新信息；尺寸可用但片段或画质检查未完成会分别说明。结果未知时重试会沿用原提交编号，避免重复排队。数字人候选方向供选材参考，不套用广告同向限制。
- **调整取用区间**：视频镜头可调整原片取用起止位置；图片不做视频入点、出点裁剪。区间过短、越界或文件离线时，先修正再保存。
- **调整镜头安排**：在页面允许的范围内增删、调整顺序或撤销操作；保存前核对影响。

数字人以原口播为声音主轴，换成补充画面仍保留原声；不能单独裁剪原人物画面来改变口播时间。广告须保证镜头时长覆盖配音，且素材有转场所需余量。

核对完成后点击 **确认粗剪并锁定画面**。有缺失镜头或主声不可用时，先解决页面提示的问题。

镜头编辑保留其他镜头的人工反馈；撤销删除或重做新增时，一并恢复该镜头保存的反馈。相同且仍有效的画面锁定重复提交不会使包装确认失效。实际改稿、换声、换镜头或正式返工后，仍须重新检查并确认受影响的步骤；撤销编辑不等于恢复旧审片批准。

### 04 包装与审片：检查和修改

按工作区顺序先进入“1 · 调整包装”，设置字幕、标题、信息卡和音乐；点击“生成成片并智能审查”后，系统生成当前成片并排队检查。画面与声音一起分窗处理，页面显示当前进度；参考2–8分钟，实际受片长和服务速度影响。检查使用现有视觉模型与智谱声音服务，按服务商计费；这里只听成片中的配音、音乐、音效，不听被静音的素材原声。

在“2 · 检查成片”查看结果：左侧是问题清单，中间持续显示成片，右侧只显示当前问题。点击左侧问题即可定位；用“待核对 / 已处理 / 全部”筛选。发现问题选“去修改”；实际可接受时选“已核对，保留现状”。同类问题可显式勾选多项，点击“批量核对”，共同原因只填写一次；选择“其他原因”须补充说明，每项仍独立留存记录。切换问题回看会保留本页未提交说明；保存失败也保留选择与输入，可重试。提交后可修改说明并保留原记录；已批准或历史版本只读。声音显示“听感证据不足”时不代表通过，需要人工回听；仍须完整观看当前成片后再确认。声音检查当前为试用能力。

已完成任务：交付页点击“修改视频”进入分类返工，旧成片和交付保留；点击“修改交付信息”调整封面、标题和发布文字，重新导出即可，无需重新渲染。在包装回看页点“修改本版包装”才能编辑，不能直接改写已确认版本。

### 包装调整

包装编辑器按三栏使用：左侧选择方案、字幕、音乐或具体元素，中间查看画面与调整位置，右侧修改当前项。字幕支持字体、字号和颜色；标题、信息卡等沿用各自的样式、文字、位置和缩放设置。拖动只展示布局示意，应用后需重新生成真实预览。未应用的修改需先保存或取消才能切换元素。窄工作区点左侧项目打开操作侧栏，点“收起”返回画面；“展开工作区”可扩大编辑空间，退出后恢复普通页面。顶部制作步骤样式保持。


数字人和横、竖版广告的“生成真实预览”现在连续播放完整时间轴，包含完整口播和全部镜头；旧版抽样预览需要重新生成。生成耗时随片长和电脑速度变化。保存字幕位置后重新生成预览，字幕按同一画布坐标显示；不需要再次拖动来补偿位置。

一键生成的新文字包装会优先分行、保持可读字号，并避开字幕和同时出现的其他元素。字号过小、显示时间太短或位置重叠会提示核对；人工位置保持原设置。规则只能检查排版，不能保证每个镜头构图都合适；可用包装预览检查布局，最终成片仍须完整观看，尤其检查人物、数字和重点信息。

选择推荐方案或本片草稿，检查字幕、背景音乐，以及需要启用的标题、信息卡、Logo、水印、贴纸、花字和音效。

点击 **一键生成整套包装** 前，先核对按钮附近的模型、发送范围与费用提示；点击即发起本次调用，不再重复弹窗。单独生成某类元素仍会确认本次范围。有可用锁定画面时会发送最多 8 张真实源帧；Agent 任务也可仅为本次建议使用内置视觉模型。确认只允许按当前包装协议生成可编辑草案，不代表认可建议内容、素材使用权、完整观看或发布。协议或模型变化后，刷新页面再确认本次调用；无需手工创建批准文件。

1. 先点击 **生成 AI 包装建议**，由 AI 根据确认文案和已锁定画面安排标题、重点信息与出现位置。也可点尚未添加的“开场标题”“信息卡”等按钮，只生成该类建议；结果保存为新草稿，保留原方案和人工修改。
2. 在建议卡片中点 **调整** 修改内容、时间和位置。元素按钮同时负责关闭与恢复；原内容会保留。需要自己新建时，展开 **手动添加**。
3. 提示 AI 连接需要恢复时，点 **检查 AI 连接**，测试现有视觉配置并设为默认；检测通过后返回本片生成。
4. 当前有效方案稳定保存后自动更新本地包装预览；可按需播放、拖动和试听，也可直接生成成片。预览失败时保留手动重试入口。
5. 发现遮挡、字太多、音乐压过人声或素材不合适时，修改方案；稳定保存后更新预览。
6. 点击 **生成成片并检查**，系统连续完成方案确认、渲染、技术质检及已配置的智能检查。包装预览无需完整观看。

方案修改后旧预览会标为旧版，生成成片时核对当前方案与画面锁，过期方案拒绝提交。使用“保存为我的方案”可复用样式和规则；新任务仍须生成本片内容并完整审看最终成片。

### 成片与智能审查

先处理自动质检的阻断项，再从头到尾播放当前成片。重点检查读音、字幕同步、画面匹配、转场、人声与音乐、事实和隐私。

发现问题时点击 **记录问题**，填写问题类型和说明。记录会绑定当前版本及时间点；可点 **定位问题** 回看，再点 **去修改** 进入返工。未处理的人工问题会阻止批准和导出；即使已经批准，另一窗口随后记录的新问题也必须先处理。若确认是误记，可明确撤回该问题，原完整审片和批准记录仍保留；实际修改成片则需要核对新版本。历史成片可以回看，不能代替当前版本的审片。

**最终文案、画面顺序、本片包装方案、完整观看后的成片确认，这四次人工确认都需要完成。** 自动质检通过、模型没报告问题，都不能代替你的观看判断。

成片审查不设素材权属确认项。观看时主要核对画面、字幕和声音。

### 05 交付导出

左侧回看已批准的成片及版本，右侧核对导出内容与完整保存路径。主操作固定在本步底部；返回审片不会重新生成视频。

1. 确认 **导出内容与保存位置**。需要时点 **更换目录**，选择已有、可写的本机文件夹。
2. 点击 **导出交付包**。封面和平台发布文字是可选项，未制作封面时会附带待补标记。
3. 完成后点击 **打开交付目录** 取用文件。需要核对路径或文件时，展开 **文件清单与保存位置**；导出中的暂停、取消按后台支持情况直接显示在状态条；展开 **处理详情** 查看进展和手动刷新。

软件更新后，已批准且内容未变化的成片可继续导出，不需要仅因渲染程序版本变化重复审片。若视频、文案、素材、包装或批准绑定实际发生变化，仍会阻断并提示处理。导出失败时先看右侧原因；原成片保留，修复原因后使用“继续上次导出”，不重复创建视频。

需要封面时，展开 **可选：封面与平台发布文字 → 设计封面**：

- 选择清晰、无字幕的素材底图，填写简短封面标题；补充说明和主题标签可留空。
- 选择配色，以及标题与图片分区、标题在上或标题在下的排版。左侧实时预览，底图完整保留；检查文字没有遮住人物或重要内容。
- 点击 **应用为本次封面**，本机保存高清 JPG 和排版草稿，并选入本次交付。竖屏为 1080×1920，横屏为 1920×1080，不调用 AI 图片服务。
- 页面刷新后可点 **使用上次设计** 再选入，或点 **设计封面** 继续编辑。成片版本改变后，需要为新版本重新制作。底图已移动或改变时需重新选图，已保存的封面仍可使用。
- 也可从成片手动选帧作底图，但可能带原字幕。原先的三张固定时点截图收在 **使用成片截图（备用）**，它们不是设计封面。

**平台发布文字**是发布到抖音、视频号等平台时复制填写的标题、说明和话题；不会修改视频，也不会自动发布。不需要时可直接导出；真正发布前应核对文案和封面，不能把待补标记当作成品封面。

主要交付最终 MP4、检查报告和版本记录，并按选择附带封面和发布文字。截图、封面待补标记及各项文件以实际文件清单为准，不固定承诺文件总数。当前不提供剪映原生工程导出；素材组件和时间映射不等于剪映工程。

## 调整广告读法与本片声音

适用于广告任务。数字人任务使用底片原声，读错时应修正文案或更换口播视频。

1. 在已保存并确认的广告文案中，选中需要调整的完整词句，点 **读法与试听**。
2. 读法用于纠正多音字、易读错的字音，不调整重音或强调。输入所选词句的完整同音汉字读法，例如起重设备“行车”可填“航车”；不填拼音或语气指令，无需纠音可留空。原文和字幕不变；当前暂不支持替换数字读法。
3. 点击“生成配音并试听”，核对待生成次数及费用并明确确认。首次生成完整配音，已有可复用声音时只生成需要修改的片段。

首次生成会按已保存的文案段落分别配音，以获得真实段落时长，并支持之后只改部分读法时复用其余声音。分段不是失败原因；只有完整音频生成并核验后才能应用到本片。取消前如已有部分成功，处理卡会保留已生成段数和失败原因；取消不会把旧失败改成成功，也不会自动重新调用配音服务。
4. 等待生成，试听读音和两句衔接；满意后点 **应用到本片**。生成成功不会自动应用。
5. 根据页面提示重新确认受影响的分镜、画面和包装，再审看新成片。

修改一句时可能复用其他有效句；换音色通常需要重新生成各句。打开 **历史声音** 可以试听并恢复可用的旧声音，恢复使用已有文件，不新增配音调用，但不会恢复旧成片的批准。

生成中使用 **刷新试听结果** 读取原作业。结果未知或素材变化时先核对，不要反复收费生成。

<a id="text-edit"></a>

## 用文字辅助修改镜头

在粗剪点 **文字修改**，输入具体要求，例如“删除第3个镜头”，再点 **生成修改草稿**。先检查镜头前后变化、时长和影响，再确认应用；不满意可取消，应用后可按页面撤销。

需要 AI 帮忙理解要求时，展开 **AI 理解修改要求**，按页面选定镜头并确认发送及费用。返回后点 **选择此解释，预览差异**，检查后再 **确认修改**。

目前只支持页面允许的部分剪辑操作，不是任意一句话都能完成。要求不清楚或缺少依据时，改用手动调整；不会自动替你批准成片。

## 缺画面与节奏建议

在分镜、粗剪或本任务素材页打开 **查看缺口处理清单**，先看每项缺口的具体原因。

| 提示 | 怎样处理 |
| --- | --- |
| 未分析或尚未登记 | 先检查更新、分析素材或补充人工标注，再重新核验 |
| 素材离线 | 接回原硬盘，用重新连接恢复 |
| 方向不合适、时长不足 | 选择画幅合适、连续时长足够的素材 |
| 重复分配或片段不可用 | 调整镜头或可用区间，再核验 |
| 没有匹配内容 | 先看现有候选；确实没有合适画面时再安排补拍 |

**“已有候选”不等于已用进片子。** 预览、采用合适画面后，再点“重新核验”；清单检查本身不会自动替换镜头。

AI 补画面建议可在写清实际需求后 **加入缺口清单**。人工登记的需求可展开 **修改需求**，填写新需求和原因，再 **保存并重新核验**；自动生成的需求不能在这里改写。

粗剪的 **节奏检查与建议** 提供复看线索。先“定位镜头”，再决定是否看修改草稿或手动调整。低音量区间、短镜头比例只是线索，音乐和衔接是否自然仍需试听。

## 使用包装素材和自己的音乐

“包装素材”可浏览字幕与字体、音色、音乐、音效、文字卡、信息卡、贴纸、花字和 Logo / 水印。进入本片包装方案后再选择实际使用的组合。

- **个人包装目录**：在“设置 → 存储与清理”选择位置。切换位置不会搬走旧文件；普通包装文件放进目录后仍需维护人员登记，不能仅凭复制文件就用于任务。
- **自己的音乐**：在本片“背景音乐”展开 **我的本地音乐库**，点 **连接音乐文件夹**。读取后搜索、试听、确认曲目使用权，再返回本片选曲。新增音乐后“重新扫描”，位置变化用“重新连接”。
- **音量**：有建议时，点击 **使用建议音量** 才会修改。调整后重新生成预览并试听，不要只看数值。
- **音效**：选择出现的事件或镜头，必要时在“精细调整”中设置素材内起点、播放区间、音量和淡入淡出。区间超过真实素材长度时要缩短或换素材。
- **恢复已关闭元素**：关闭可选元素会保留设置。重新启用后检查素材是否还在线，并重新生成预览。

带署名要求的音乐需在发布说明等合适位置保留署名，具体见[第三方素材说明](../../THIRD_PARTY_NOTICES.md)。

## 素材搜索、分析和 Excel 台账

### 搜索与分析

素材台账可按任务、目录或用途筛选，再搜索文件名、画面描述、标题或标签。按画面内容搜索依赖已有观察或人工标注，没分析过不代表没有这段内容。

可逐项勾选素材，或点击表头 **全选本页**；全选后再次点击可 **取消本页全选**。只选择本页在线且可用的视频、图片，其他页的选择保留；部分选中时显示半选状态。每次分析仍最多 50 项。勾选后点 **分析选中素材**。系统先在本机整理场景候选；如果继续使用视觉模型，先核对批次、发送范围和所选服务，再点 **AI 内容分析**。分析只覆盖取样范围，仍需打开片段观看。

AI 内容分析只在点击按钮后提交；本机检测完成不会自动调用模型。没有可靠估价时不显示“费用未知”或重复确认框。提交后显示“本批分析中”。结束后显示成功（含复用）、失败、未完成数量；“本批已结束”不代表全部成功。全部成功时显示“本批分析已完成”。如需重试，点击“准备重试未完成项”，重新检查范围后，再点击“AI 内容分析”；切换批次或视觉服务会重新检查本次范围。VISUAL_PROTOCOL_INVALID 表示服务返回结果格式不符合要求，该项尚未生成可用分析结果。

旧素材已有场景或画质缓存，但缺少尺寸、时长时，仍需完成本机检测；已有 AI 内容分析继续复用，不会因此重新收费。

本机检测进度分别显示已完成、失败、检测中或等待的数量。场景划分完成但画质检测未完成时显示“等待画质检测完成”，不计入已完成，也不标为失败。任务停止后未完成项可重试；实际失败保留具体阶段及原因。

抽样偏暗、疑似重复或运动判断不能直接决定素材是否可用。你可以核对后修改片段使用标记；本功能不会自动清空或整理原素材库。

### Excel 台账

点击 **导出 Excel 台账**，获得当前筛选范围的记录。只改浅黄色可编辑列，保留资产、可用片段两张表和只读字段；不要加入公式、宏或外部连接。

修改后点 **导入 Excel 台账**，先看差异与冲突，再 **应用这些变更**。删掉表格行不会删除原素材；要停用应修改使用状态。出现版本冲突时重新导出当前数据再核对，避免覆盖其他人的修改。

<a id="ai-review"></a>

## 智能审查与补充检查

### 模型辅助内容检查

在成片审查展开 **模型辅助内容检查**，按页面选择可用服务，核对发送范围与费用后开始。当前会发送有限成片抽帧和文案，不检查所有连续画面。

模型的一般建议供参考，不要求逐条确认。标为待核对或冲突的问题需要定位回看并修改；有具体依据决定保留本版时，填写说明并 **确认保留**。技术阻断项与人工记录的问题仍须处理。

AI 检查停止，不等于视频生成失败。页面显示已完成段数、停止原因和下一步；内部错误码收在“诊断详情（供维护人员查看）”。如果提示报告时间点与引用画面对不上，该报告未被采用，不能据此认定视频有问题；相同请求会读取原有无效报告，因此不提供盲目重复提交。

尚未确认本版时，直接点击视频播放，从头检查画面、字幕和声音，处理已记录的问题。AI 未完成或覆盖不全时，在最终确认处勾选人工检查声明，再点 **确认成片，进入交付**；声明与批准一次保存。未看完或仍有未处理问题时会说明原因，人工确认不会把 AI 结果改成通过。

本版已经完成人工审片时，直接进入 **交付导出**，核对封面与发布文字，点击 **导出交付包**。旧的 AI 检查失败记录不会再覆盖导出页面；“回看检查结果”可查看详情，无需重复审片或重新生成视频。

### AI 声音检查（试用）

当前候选质检合格且尚未批准时，可展开 **AI 声音检查（试用）**，加载需要检查的区间，选择已配置账号，确认发送及费用后开始。单次最多检查 30 秒，发送所选成片音频和指令，不发送文案或画面。

**信息流广告的镜头素材只使用画面，素材视频原声不进入成片，也不参与听审。** 成片声音由确认配音、选用的背景音乐和音效合成；声音检查读取当前渲染成片的最终音轨。数字人口播的主配音不属于这里的镜头素材原声。

**“返回文字待复核”不表示检查通过。** 当前完整 AI 听审尚未验收，语气、重音、情绪、读音及衔接仍需自己试听。声音检查不是出片必经步骤；它不会自动批准视频。

刷新只读取原结果。候选或输入变化后，旧结果仅供历史参考；结果未知时保留原请求，不通过换任务或反复点击绕过提示。

<a id="error-feedback"></a>

## 出错后怎样反馈

CUTROOM 会在本机自动保留近期错误。出现红色提示、操作失败或页面异常时，不必先反复重试。

1. 点击页面顶部的 **导出报错日志**。窄屏下在导航菜单中找同名按钮。
2. 把下载的 `CUTROOM-errors-….zip` 发给维护人员，并说明 **大约几点、在哪个页面、刚才点了什么、预期什么结果**。可附错误截图，截图不要包含密钥。
3. **安装失败或网页打不开：** 在 CUTROOM 安装目录双击 **导出报错日志.bat**。文件生成在该目录的 `out` 文件夹，导出后会打开位置；不需要先把工作台启动起来。

网页失去连接或授权时，按钮会先下载 `…-browser.json`，它仅含浏览器侧记录。请再运行上述 BAT，把两份文件一起提供。Python 还没有安装完成时，BAT 可导出安装/启动记录，包内会说明覆盖范围。

日志默认只保存时间、版本、错误类别、接口类别及程序代码位置，不包含 API Key、访问令牌、请求或响应原文、任务文案、素材和数据库。日志不会自动上传，导出后由你决定发给谁。后台日志约保留最近 1 MiB，浏览器保留最近 40 条；尽量在出错后及时导出。

此功能覆盖新版程序捕获到的安装、启动、接口、网页和后台作业错误。断电、磁盘无法写入、程序尚未加载或使用旧版时，可能没有记录；这时请提供截图和当时操作，不能把“没有日志”理解为“没有出错”。

<a id="troubleshooting"></a>

## 遇到问题怎么办

任务顶部始终显示当前进度；回看已完成步骤时，会另外标注“正在回看”，不会改变任务进度。四个制作阶段下面列出该阶段的步骤，分别标明已完成、当前步骤和未开始。

处理卡片会写明正在做什么，例如“配音生成”“音乐与音效分析”或“交付文件导出”。按卡片上突出显示的按钮操作：

- **继续处理**：页面确认已有进度可以继续时才显示。
- **返回本步骤**（按钮显示具体步骤名）：查看已保存的文案、画面或设置；不会启动生成。
- **导出报错日志**：结果尚未确认时，下载诊断文件交维护人员核对。
- **重新连接素材**：接回移动硬盘或指定素材目录的新位置。

取消、失败或中断后不再显示剩余时间。错误细节收在“查看处理详情”中；“刷新状态”只更新显示，不重新生成。


| 情况 | 先做什么 |
| --- | --- |
| 工作台打不开、提示未授权 | 重新双击原目录的“启动CUTROOM.bat”；确认没有移动目录 |
| 安装提示环境不完整 | 保留错误窗口和原目录，联系维护人员；不要删除任务或搬动运行环境 |
| 模型不可选、检测过期 | 检查账号、服务开通和检测结果；明确费用后再检测 |
| 任务一直处理中 | 查看后台进度；大素材核验可能需数分钟，不要重复新建作业 |
| 模型请求失败或结果未知 | 先看原作业及页面恢复说明；仅使用页面明确提供的恢复或重新确认费用入口 |
| 素材离线或移动硬盘盘符变了 | 接回硬盘并“重新连接”，不要建立重复素材库 |
| 包装预览失效 | 核对当前设置，重新生成并观看真实预览，再确认方案 |
| 其他窗口已修改任务 | 刷新任务并核对最新内容，不要继续提交旧草稿 |
| 仅质检中断、视频没变 | 在返工中选“技术问题 → 仅重做质检（复用原视频）”；条件变化时按提示重新生成 |
| 上次导出没完成 | 恢复保存目录、空间或权限，再使用“继续上次导出” |
| 已导出的包缺文件 | 核对交付信息，点“重新导出完整交付包”；旧包保留 |
| 空间不足 | 在“设置 → 存储与清理”先查看缓存范围、移入可恢复区，确认永久清空后释放空间 |

修改文案、声音、镜头或包装后，旧批准不能自动用于新成片；按提示重新完成受影响步骤。只改封面或发布文字时，可沿用当前有效视频，重新导出交付包。

仍无法继续时，把任务名称、当前步骤、错误提示及所点按钮发给维护人员。不要附带密钥或带登录凭据的链接。

## 14. 升级、回退和卸载

### 14.1 双击更新

日常升级使用原安装目录中的 **产品更新升级.bat**，不用重新添加 MCP，也不用移动任务文件。

1. 保存页面草稿，等待生成、渲染等任务完成。退出 WorkBuddy、豆包等已连接的助手。
2. 重启电脑后，**先运行产品更新升级.bat，再打开 CUTROOM**。关闭浏览器不会停止后台；升级入口会检查运行状态，不会强行结束任务。
3. 选择 **联网检查并下载新版**。无需 GitHub 账号；网络不通时，也可选择维护人员提供或自己已下载的官方 Windows ZIP。
4. 检查显示的当前版本和新版本，输入 **Y** 开始，等待“升级完成”。升级时不要打开 CUTROOM 或重新连接 MCP。
5. 从原来的 **启动CUTROOM.bat** 打开。在 WorkBuddy/豆包中重新连接一次 MCP，即可加载新版工具；不要删除连接重建。

**Beta.10 及更早版本没有升级入口：** 下载新版并解压到另一个文件夹，运行新包的 **产品更新升级.bat**，选择原安装目录，再选择刚下载的 ZIP。不要把新包手动覆盖到旧目录；升级完成后继续使用原目录。维护人员改过程序、使用开发版或更换过运行环境时，工具会停止并提示维护处理。

本入口只支持兼容的程序原位升级，任务、素材、成片、Windows 凭据和 MCP 配置保留。涉及数据库结构或依赖变化的版本由维护人员处理。首次切换到编译发行包后，旧预览可能需要重新生成；按页面重新检查，不把旧批准直接套到新结果。

升级失败时，按提示使用 **恢复上次未完成的升级**；中断期间不要启动工作台。程序备份在原安装目录的 `runtime/software-updates`。仍无法恢复时，保留现场并导出报错日志，交维护人员处理。

### 14.2 回退和卸载

不要让旧版直接打开已经由新版升级的数据。回退需要恢复升级前备份；卸载前先确认任务、成片、声音和素材都已保全。维护人员按[升级与恢复说明](../operations/cutroom-maintenance.md)执行。

## 可选：连接 WorkBuddy 或豆包工作

MCP 是让聊天助手调用 CUTROOM 工具的连接方式。连接后，你可以在 WorkBuddy 或豆包工作中查询任务、提交规划和使用已支持的剪辑建议；视频仍在本机 CUTROOM 中制作。只使用网页的同事不需要安装 MCP。

[连接前准备](#mcp-preparation) · [添加到 WorkBuddy](#mcp-workbuddy) · [添加到豆包工作](#mcp-doubao) · [连接故障](#mcp-troubleshooting)

<a id="mcp-preparation"></a>

### 连接前准备：只做一次

1. 先完成 CUTROOM 安装，并用 **启动CUTROOM.bat** 打开工作台，确认能看到自己的任务。
2. 找到这个工作台实际使用的安装目录，里面应有 `安装CUTROOM.bat`、`启动CUTROOM.bat` 和 `scripts` 文件夹。不要选源码下载目录、旧版目录或另一份测试安装。
3. 在该文件夹的资源管理器地址栏输入 `powershell`，按回车。复制下面的命令并执行，等待成功后再继续；首次需要联网。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-mcp.txt
```

**以下默认接入步骤适用于“同一安装目录、默认任务库、默认工作台端口 8765”。** 如果维护人员为你设置过独立任务库、自定义端口或多份安装，先由维护人员按实际实例配置，不要直接运行默认连接脚本。否则可能连到空库或另一批任务。已有 26/26 工具且任务正确的连接不用重新安装。

提示找不到 Python、缺少模块或安装失败时，保留错误窗口，交维护人员处理，不要删除 `.venv` 或任务目录。接入说明中的令牌只用于本机连接，不是豆包配音 API Key。

<a id="mcp-workbuddy"></a>

### 添加到 WorkBuddy

**首次添加：**

1. 在上一步的 PowerShell 窗口执行检查：

   ```powershell
   .\.venv\Scripts\python.exe scripts\probe-cutroom-mcp.py --client workbuddy
   ```

   看到 `ok: true`、`toolCount: 26`、`allowedTaskActionCount: 4` 后再继续。这一步使用临时库检查程序，不证明已经连接到你的任务。

2. 按 `Win + R`，输入 `%USERPROFILE%\.workbuddy` 并打开。若已有 `mcp.json`，在同一文件夹复制一份作为备份；尚无此文件可继续。
3. 回到 CUTROOM 目录的 PowerShell 窗口执行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\install-workbuddy-mcp.ps1
   ```

   脚本自动添加或更新 `cutroom`，保留其他 MCP；不需要再重复点击“添加 MCP”。

4. 打开 WorkBuddy 的 **MCP 服务管理**，找到 `cutroom`，打开启用开关；如果出现信任提示，确认后继续。已有该项时点击右侧 **↻** 或错误提示下的 **重连**。
5. 看到绿点和 **26/26 个工具已启用** 后，新建一个 WorkBuddy 会话。若仍显示旧数量，完全退出 WorkBuddy，再重新打开。
6. 在新会话发送下面这段检查指令，并核对返回的任务与你网页中的任务一致：

> 请通过 CUTROOM MCP 查询系统状态和已有任务，不创建任务、不修改内容、不执行生成。确认客户端身份为 workbuddy、工具数为 26、允许的任务动作数为 4，并列出已有任务供我核对。

**以后每天使用：** 打开同一份 CUTROOM 和 WorkBuddy 即可。MCP 程序由 WorkBuddy 启动，不需要另留一个 MCP 服务窗口。更新安装目录后，先由维护人员更新连接路径和任务库绑定，再点重连；仅重连不会自动下载或升级 CUTROOM。

<a id="mcp-doubao"></a>

### 添加到豆包工作

此流程用于与 CUTROOM 在**同一台电脑**上的豆包工作客户端，使用本地 HTTP 连接。豆包工作的 MCP 连接与 CUTROOM 设置里的“豆包配音账号”是两项独立配置。

**首次添加：**

1. 完成“连接前准备”。在 CUTROOM 安装目录的 PowerShell 窗口启动连接服务：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\start-doubao-work-mcp.ps1
   ```

   保持这个窗口开启。正常启动后会显示 `http://127.0.0.1:8766/mcp`；它是 MCP 地址，不是网页工作台地址。

2. 在同一安装目录**另开一个 PowerShell 窗口**，获取本机的连接信息：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\show-doubao-work-mcp-config.ps1
   ```

   输出的 `Authorization` 值包含本机访问令牌，只复制到下方连接器字段，不发给聊天助手或群聊，也不要截图分享。

3. 在豆包工作打开 **插件 · 技能 · 伙伴 → 新建自定义连接器**。入口名称随客户端版本可能不同；找“自定义连接器”或“MCP”添加入口，按字段填写：

   | 字段 | 填写内容 |
   | --- | --- |
   | 名称／服务器名称 | `cutroom` |
   | 传输类型 | `HTTP`（Streamable HTTP） |
   | 服务器 URL | `http://127.0.0.1:8766/mcp` |
   | 自定义 Header 名称 | `Authorization` |
   | 自定义 Header 值 | 上一步输出的完整 `Bearer …` 值，保留空格，不带 JSON 引号 |

   不要把整段 JSON 粘进一个字段。若客户端没有 HTTP、自定义 Header 或本地服务接入能力，先交维护人员核对客户端支持范围。

4. 保存并启用连接，确认能发现 **26 个工具**。新建会话后发送：

> 请通过 CUTROOM MCP 查询系统状态和已有任务，不创建任务、不修改内容、不执行生成。确认客户端身份为 doubao_work、工具数为 26、允许的任务动作数为 4，并列出已有任务供我核对。

5. 对照网页核对任务。工具数量正确但任务不同，仍属于连接目标错误，先不要创建或修改任务。

**以后每天使用：** 打开 CUTROOM 后，先运行第 1 步的启动命令，保持服务窗口开启，再使用豆包工作；连接信息未变化时无需重复添加。关闭服务窗口后连接会断开，重新启动服务再重连。停用时可按 `Ctrl + C` 关闭服务。

<a id="mcp-troubleshooting"></a>

### MCP 连接失败或工具数量不对

| 看到的情况 | 怎么处理 |
| --- | --- |
| WorkBuddy 显示 `Connection closed` 或红点 | 表示后台连接被关闭；请维护人员核对该连接实际使用的 Python、依赖和启动日志。修复后再点“重连”，不靠反复重连修复缺失依赖 |
| 仍显示 12/12 或 14 个工具 | 常见于旧目录或旧会话；核对连接路径、实际任务库及新版代码，再重连并新建会话。GitHub 更新不等于本地连接已更新 |
| 显示 26 个工具，但任务为空或不对 | 先停止任务操作，让维护人员核对工作台与 MCP 是否使用同一个任务库；不要重建同名任务来替代旧任务 |
| 显示已连接，但聊天提示找不到工具 | 确认已启用且完成信任，新建会话；必要时完全退出客户端再打开 |
| 豆包工作连接被拒绝 | 确认第 1 步的服务窗口仍在运行；检查地址与端口是否一致，端口冲突交维护人员处理 |
| 豆包工作提示 401／未授权 | 核对 `Authorization` 字段及完整 `Bearer …` 值，令牌必须来自当前这份安装；不要填配音 API Key |
| MCP 能查任务，但网页打不开 | 用匹配安装的启动入口打开网页；MCP 连接与网页启动独立，维护人员需核对返回的工作台地址 |

连接检查只查询本机服务和任务，不触发 CUTROOM 配音、视频生成或模型分析；聊天客户端自身的用量按其规则计算。

### 接好后怎样开始制作

创建新任务时选择 **当前 Agent 规划**。看到“等待 Agent 提交规划”后，回到所用客户端继续，再返回 CUTROOM 检查。原来由“CUTROOM 自己规划”的任务不会因接上 MCP 自动改成 Agent 模式。

Agent 模式负责文案与分镜等规划，配音、视频生成等生产服务仍使用 CUTROOM 中的账号，并可能计费。最终文案、画面顺序、包装方案和完整审片四步仍由你在网页确认，MCP 不代替这些确认。

Codex 接入、独立任务库绑定、HTTP 检测、回滚和维护命令见[Agent 客户端操作说明](../operations/cutroom-agent-mcp-clients.md)。未配置 Agent 时，直接使用“CUTROOM 自己规划”。


### 创建、草稿和后台检查（Beta.13）

创建分两步：选择类型、填写内容与素材。点击“创建任务并填写文案”后自动检查；无阻断或仅提示“下一页填写文案”时直接创建；目录离线等其他提醒仍须核对。素材初检在后台进行，文案页可以同时填写、保存和确认。初检刷新不会覆盖正在输入的文字；后续分镜仍须通过素材检查。

保存失败时，文案旁会持续显示“草稿尚未保存”。请先复制到记事本，勿把点击按钮当作保存成功。后台显示心跳超时且长时间无进展时，先保存工作或复制文案，关闭 CUTROOM 工作台服务后重新启动（仅刷新浏览器无效）。启动后会按租约恢复中断状态；有“继续素材检查”按钮时点击它。不要手工修改数据库，也不要对未知付费结果反复重试。

“读法与试听”用于已确认文案中的选中词句；未确认时，按钮旁和点击提示会说明操作顺序。后台作业优先参考本机同类完成记录估算耗时；没有记录且已有可计算进度时按当前速度估算。没有依据时显示已处理时间和数据不足说明，不承诺完成时间。

视觉分析兼容完整 JSON 对象外的一层 Markdown 代码围栏，随后仍检查 JSON 结构、必需字段和取帧证据；截断、重复键和夹杂解释的响应仍失败。此兼容不新增远程请求，不会自动重试付费分析。小样本检测通过不代表每条真实素材都能成功；旧失败项不会自动转成成功，需重新准备未完成项，再点击“AI 内容分析”。

### 包装方案：按这5步操作

1. 核对模型与费用说明，点“一键生成整套包装”，参考1—3分钟。页面先显示准备画面和文案，再显示已提交/AI生成中；无需重复点击。成功后自动显示新建议；已有草稿会保留。
2. 检查标题、信息卡等。已启用元素可点一下关闭，再点恢复；卡片“调整”修改文字、时间和位置。人工调整建议预留1—3分钟，每次保存约1—5秒。
3. 需要背景音乐时勾选“使用”，展开“比较其他音乐”，试听后选择；不需要就跳过。建议预留1—2分钟。
4. 当前有效方案稳定保存后自动更新全片包装预览，可按需播放；首次生成失败可手动重试。实际耗时随片长和电脑速度变化。
5. 点“生成成片并检查”；系统自动渲染并检查，参考2—10分钟。完成后直接播放最终成片，完整看完再确认进入交付。

页面显示的是初始参考范围，实际随素材数量、片长、网络和电脑速度变化。AI等待超过参考范围会明确提示；“刷新处理状态”只核对状态，不重新付费调用。生成失败时已有方案保留，页面显示中文原因，不需要连续重试。


### 包装方案：生成、调整与复用

包装页始终编辑一份当前方案，刷新后恢复同一草稿。选择“简洁商务”或“重点突出”只设置下一次 AI 生成的风格，不会切换或清空当前内容；手动调整不再另设“自选组合”。

1. 在“当前包装”里选择生成风格，点“一键生成整套包装”。确认后统一安排适合本片的标题、信息卡、花字、音乐等；不必逐项发起。预计耗时和已等待时间就在按钮下方。
2. 生成完成后自动显示新草稿。点已有元素关闭／恢复，点卡片“调整”修改文字、时间和位置。“自行添加元素”用于手工补充。Logo／水印始终需主动添加。
3. 包装预览自动更新，可按需检查文字、位置和声音；点“生成成片并检查”继续，最终成片须完整审看。耗时随片长与电脑速度变化。

“历史方案”在弹层中选择本任务以前的草稿。“我的模板”在独立弹层中选择已保存的复用样式；“保存为模板”只保存样式和出现规则，不复用本片文字和具体秒数。当前草稿已保存并不表示已经保存为模板。

新请求处理中只显示本次进度。失败保留当前方案，不自动重发；具体诊断可展开查看。刷新保留草稿选择使用当前浏览器的本地存储，内容仍保存在任务库中；换浏览器可通过历史方案找回。


包装草稿保留：刷新会回到本任务刚才编辑的方案。再次一键生成时，已人工调整的元素继续保留；AI 没有重新安排的已有类别也会带入新草稿。旧方案可从“历史方案”打开。


### 字幕外观与画面拖动

在包装方案的“字幕”区点击 **调整字号、颜色与位置**：在画面上拖动文字，拖右下角调整文字区域宽度；右侧滑杆调整字号和描边，色块调整文字、重点词、描边和底色，底色不透明度为0时不显示底色。也可用顶部、居中、底部快速定位。

点击“保存设置”写入当前方案，刷新仍保留；点击“取消”放弃本次调整。已生成的方案会保留历史副本。开场标题、信息卡等点卡片“调整”，同样可以拖动和缩放，再点“应用并定位”。

拖动界面是即时布局示意；字体实际形状、换行和叠加效果以“生成真实预览”为准。改完后需要重新生成预览。本机32秒任务的4段预览此次生成约2分钟，其他视频受片长和电脑速度影响。当前没有旋转、吸附线或多元素同时选择；卡片字体颜色仍由所选卡片样式决定。


### 更新后仍看到旧界面

安装更新不会自动替换已打开标签页的界面。看到“界面已更新”提示时，先保存编辑，再点“刷新到新版”。没有该提示的旧版页面，更新后首次手动刷新一次；服务断开重连不会自动清空正在输入的内容。


### 任务侧栏与包装确认

桌面任务页各步骤统一保留左侧任务导航。点侧栏顶部“折叠”收起，点“展开任务”恢复；切换步骤与刷新保留选择。

包装预览不再要求完整播放，未观看预览也能生成成片。最终成片保留完整观看要求，修改后生成的新成片须重新观看；当前版本未看完、技术质检阻断或仍有未处理问题时，最终确认不可用。


成片生成失败或中断时，页面显示“已停止”，不会在后台自动继续。先按具体原因恢复缺失数据，再点击“重试处理”；暂停任务仍显示“继续处理”。已恢复字幕时间轴、重点词与已确认镜头方案时，不必为了旧版分镜文件重新调用 AI 推荐。安装版使用自带的渲染组件，不需要另行安装开发工具。工作区不再反复展示创建初检日期或内部观测时间；当前阶段、处理状态和预计耗时继续显示，原始时间保留在诊断日志中。


### 成片审查：先看视频，再确认交付

成片生成后，左侧播放视频，右侧显示需要处理的问题和下一步操作。直接点击视频播放，从头观看；观看进度与“确认成片，进入交付”在同一区域。发现问题可在播放器下方“记录问题”，处理后再确认。

重复镜头属于观看提示，默认收起。AI 内容检查、声音检查、全部技术检查明细及修改记录集中在“更多检查与记录”；影响确认的内容检查问题仍在右侧提示，不会藏在折叠区。素材权属不再作为成片审查项目，也不要求逐片确认；历史登记保留，不代表系统自动确认权属。

旧成片如仍停留在此前的检查失败状态，点击“重新检查成片”，沿用已有视频重新运行本地检查。源文件或包装已改变时，仍需按提示回到相应步骤处理；软件运行组件升级时，旧成片可能需要保留为历史版并重新生成；不把缺失文件或视频质量问题当作通过。


### 制作步骤导航

勾选节点表示该步骤已完成；强调色及“正在查看”表示当前打开的页面。点击已完成节点可回看结果，未开放步骤暂不可点。窄窗口自动分行，无需左右拖动。


### 按素材库查看镜头

从左侧“镜头素材”进入，先选“项目素材”或“通用素材”，再选择具体素材库。项目素材用于园区实拍与数字人原始口播，补充画面统一使用通用素材，不设项目内专属补充素材。

中央可切换缩略图和列表。点文件或“查看片段”，在右侧预览；通过片段下拉、上一个／下一个选择画面，播放直接定位原片时码。默认只展示当前片段的标题、时间范围与画面重点；“修改当前片段”可改描述、时间与使用标记，备注与技术信息另行展开。列表和详情分别滚动。

左侧“新建项目素材库／新建通用素材库”打开独立窗口，创建素材库并关联本地文件夹；成功后进入新库。当前库的路径、扫描与重连使用“管理当前文件夹”。素材分析、Excel导入导出与常用筛选直接显示；素材授权状态不再作为浏览或审核项。切换库会清空上一库勾选，刷新会保留本标签页所选库。从任务返回全局素材库时，浏览不再受刚才任务的素材范围限制。

素材分析分为本机检测和 AI 内容分析。本机检测补齐时长、尺寸和横竖方向，并检查场景与画质，不调用视觉模型；检测完成后显示模型选择、分析范围和“AI 内容分析”按钮，点击才调用模型；不自动进入远程分析。已有结果全部可复用时直接展示结果。耗时优先参考当前作业估算；数据不足时显示初始范围，本机检测按每项约30秒—3分钟、AI按待处理区间约30秒—2分钟参考，实际受片长、电脑、网络及服务速度影响。


## 包装素材：分类浏览与新增

从左侧“包装素材”进入，默认显示配音音色。先选分类，再点击素材查看右侧效果或试听；搜索和来源筛选只作用于当前分类。窄窗口点击素材展开详情，关闭后返回列表。

- 顶部“管理字幕样式／管理背景音乐”等按钮管理当前分类。全库文件检查另标明“所有分类”。
- 音色从已配置的配音服务读取；“管理配音音色”刷新目录，“添加配音音色”进入服务配置。生成试听可能计费，需单独确认；已有样音可直接播放。设为常用音色不改已有任务。
- 字幕、卡片和花字通过选择基础样式、命名和配色另存为个人样式。已有样式不被覆盖。
- 背景音乐、音效、贴纸、Logo通过“添加”选择本地文件，复制到个人目录后登记；原文件保留。重复文件直接定位已有素材，个人素材可在右侧重命名。
- 本页管理可复用素材；本片的文字、出现时间、大小和位置仍在任务中调整。预览字体与配色供选材，最终效果以任务中的真实预览为准。


## 任务素材目录与分析（2026-10-14）

打开任务顶部 **本任务设置 → 修改素材目录**，选择已登记的本地主素材目录和需要的额外目录，再点 **保存本任务素材目录**。新文件夹先到“镜头素材”登记，再返回选择。保存只影响当前任务，不更改其他任务或全局库路径；保留已完成分析及口播确认。固定数字人口播单独绑定，不会因更换补充目录而换底片，也不会把口播目录的其他文件带入候选。

新建任务不再默认启用通用目录；只有明确勾选才扩展范围。正在处理或画面已锁定时暂不能修改；旧镜头仍引用要移除的目录时，先替换镜头或保留该目录。

数字人口播需要基础文件、视频/音轨、时长检查与口播校对，不必为了使用原口播额外做AI画面内容识别。素材分析的本机阶段用于场景划分与画质检查；完成后由用户选择是否点击AI内容分析。抽帧超时会说明可重试，不能据此断定视频损坏；旧失败记录可能没有保存具体原因。


## 补充画面：左右对照选材（2026-10-14）

在“补充画面”找到要调整的口播段，点击 **更换画面**。左边显示这段口播和当前画面，右边列出本任务已选择目录中的候选。点候选只预览，确认合适后点击 **使用这段画面**；关闭、取消或按 Esc 都保留原选择。选材不重新生成声音，也不改变本段口播时间。

候选太短时仍能预览，但不能应用；选择更长的片段或照片即可。当前已经使用的画面不必重复选用。想让同一句口播切换多个画面时，再展开 **一段内使用多个画面 → 为本段再选一个画面**；确认后会重新分配本段各画面的时间，口播总时长不变。

顶部显示当前已有多少段使用补充画面，不再把上次推荐的未采用数量当作当前待办。可以自行更换，也可以保留数字人继续生成粗剪。**查看未采用建议的原因（可选）** 中的明细提供通俗原因与 **去这段选画面** 入口；时长/定位依据和 AI 补拍建议默认收起，不是选材必经步骤。选材仍只使用任务设置中明确选定的目录。

点击“预览与取用区间”打开左右弹窗，左侧播放源画面，右侧查看来源与时间。补充视频可调整起点并点击“应用取用区间”；关闭或 Esc 放弃未保存改动。数字人原画面与口播固定同步，无需调整区间。候选窗口显示本任务素材目录；同一文件可能划分为多个片段，候选不等于自动推荐。当前选择统计按已选镜头更新。

画面列表按可见位置加载缩略帧，打开弹窗后再播放视频。加载候选只读取已选素材与现有分析，不会再次调用 AI；候选数量表示区间数，不是文件数。自动推荐仍需核对内容和连续时长；当前采用“自动初选、人工复核”，不保证每条口播都能自动找到合适素材。

## 磁盘清理与任务记录保护

进入 **设置 → 存储与清理**。程序、内置字体与音乐、任务备份也必须保留。不要在资源管理器里整目录删除 `runtime` 或 `out`，其中可能保存字幕时间轴、配音、编辑记录和成片。

1. 点击“查看可清理缓存”，核对数量、体积和文件清单；当前仅包括登记过的缩略图、素材预览、代理与试听缓存。
2. 点击“移入可恢复区”。系统先备份任务记录，再移出缓存；此时仍占空间，可以点击“恢复缓存”撤销。
3. 确认不再需要后，在“已移出的缓存”点击“永久清空这批缓存”，再次确认后才释放空间。原素材、任务记录和成片不在此范围内。

工作台运行且没有任务处理或排队时，约每 5 分钟自动备份任务数据库与托管任务小文件；也可点击“立即备份”。保护目录位于 `%LOCALAPPDATA%\CUTROOM\task-protection`，与安装目录分开，具体路径和最近备份时间在页面中查看。保留最近三份数据库快照，并额外保留最近一份含任务记录的有效快照，避免后续空库备份淘汰旧任务；单文件超过 64 MB、单次超过 512 MB 或无法读取的文件会显示未备份。此功能不备份原视频、全部素材库或成片，也不能代替其他硬盘上的备份。

误删后点击“检查缺失文件”。有同一任务版本的有效备份时，可点击“恢复可补回的文件”；只补缺失文件，现有文件不覆盖，人工确认不代替。没有备份则进入对应任务处理；原口播缺失应重连硬盘或重新关联。这里检查已备份文件、已确认文案及登记的原口播，不是全盘检查。任务数据库本身丢失时网页可能无法启动，保留保护目录，交维护人员离线恢复。

任务正在处理或排队时，清理、备份和恢复暂停。历史成片、旧交付包以及数据目录迁移不在本页自动处理范围内。



### 模型连接需要检测时，如何继续生成成片

“AI 检查尚未启动，模型连接需要检测”表示检查服务配置或检测状态需要更新，不是视频内容错误。确认包装后，精剪与本地技术质检仍可继续；AI 未执行不会记为通过。

需要 AI 检查时，点击“前往模型与配音”，完成相关模型配置与检测后，回到当前成片点击“开始/重新进行 AI 检查”。也可以完整观看当前成片，处理已记录的问题，在最终确认处勾选人工检查声明后一次确认进入交付。最终交付仍要求技术质检及人工确认条件满足。检测与智能检查可能按服务商收费。

### 数据库缺失与转写中断

已使用过的任务库丢失或变成零字节时，启动会停止并提示 `STORAGE_DATABASE_MISSING`，不会自动创建空库。先保留安装目录与任务保护目录，由维护人员按维护说明恢复数据库；不要删除保护记录来绕过启动检查。全新安装仍会正常初始化。

新版口播识别已完成、但写入结果时中断的任务，可使用页面提供的“继续处理”。系统会核对原视频、文案和已保存结果，匹配时继续完成写入；不会重复识别。旧版不完整结果或输入已变化时仍会提示核对，不覆盖未知文件。

本版本的 AI 发布文案建议尚未开放。可在交付页手动编辑标题、说明与话题，正常导出；镜头缺口仍通过本地素材选配，AI B-roll 生成尚未接通工作台，不将已配置模型视为已可生成。


换音色试听已生成但镜头时长不足时，可选择“保留试听，先调整画面”，完成粗剪调整后重新打开并找回上次试听。刷新只核对原请求和当前镜头；“取消”仍会丢弃草稿。文案阶段先应用声音后，独立分镜规划沿用该声音及实测分句，不另行生成旧音色。


### 导出前校验未通过

若提示“导出前校验未通过”或“已审片的输入依赖校验未通过”，原成片仍保留。先打开交付底栏“处理详情”；需要排查时点击“导出报错日志”。这一提示本身不能判断哪份内容改变，也不代表必须重新审片。不要连续重试；原因处理后使用“继续上次导出”。磁盘空间不足、目录不可访问等已确认原因会单独提示。


## 数字人口播工作区

口播核对采用左侧原文与疑点、中间原视频、右侧核对操作。点击原文或疑点回听实测时间范围；识别不确定或无法定位时保留原文提示，通过原视频回听，定位本身不代表内容正确。

“确认本处一致”和“记录问题”会保存到当前文案、底片和转写版本。刷新可恢复；另一个页面已更新时提示重新载入，避免覆盖。记录问题需要说明；处理完后仍需原整体口播核对确认，不能用局部保存代替。改稿或换底片后旧记录随历史保留，不能自动批准新版本。

补充画面采用镜头导航、画面预览、对应口播与镜头操作三栏。补充素材单独静音预览，不冒充带原口播的合成效果；回听原口播使用真实时间范围。粗剪、包装、检查成片的展开工作区及顶部步骤条继续保留。


口播核对中的“问题说明”：已提交的记录由后台保存，刷新后可恢复；未提交文字仅在当前打开页面的会话内暂存，站内切换页面再返回可继续填写。更换文案或转写版本后使用新版本的草稿，不沿用旧版本说明。保存中可以浏览其他内容，保存结果不会把页面切回旧疑点或打断当前播放。


口播核对：左侧“粘贴 / 修改原文”可编辑整篇文案；修改后需保存并重新核对，关闭编辑框会保留当前草稿，未保存时不能确认旧文案。可在编辑框内选择“恢复已保存原文”撤回草稿。右侧“记录问题”展开说明并保存，已记录待修改的问题会阻止整体确认；核对完成后由本人点击“确认与口播一致，继续”。原视频信息、换底片和核对记录位于工作区上方入口。小屏可使用“展开工作区”放大视频，收起不重置当前视频和核对内容。


任务详情侧栏按任务概况、素材范围、原口播文件和模型配置分组。原片长度指原口播视频本身，可能与倍速后的成片时长不同。修改素材目录不会替换口播底片；更换底片仍需预检，并按当前进度核对返工影响。口播工作区保留较大的最低高度，小屏可向下滚到工作区或点击“展开工作区”。

修改原文并保存后，先点击“确认文案，开始核对”确认本次新稿，再等待产品重新转写。当前版本没有核对结果时，不代表没有疑点；完成回听后再点击“确认与口播一致，继续”。

### 展开工作区与检查弹窗

口播核对、粗剪调整、调整包装及检查成片的“展开工作区”统一放在工作区顶部工具栏右侧；展开后原处显示“收起工作区”。切换大小保留当前播放器和编辑状态。

“节奏检查与建议”分为本地节奏检查和可选 AI 画面建议。本地检查不调用 AI、不计费；AI 建议须选择可用视觉服务并确认本次发送和费用。“发送内容与检查范围”可展开查看具体数据和限制。没有可用服务时会说明原因；“刷新已有结果”只读取原结果，不再次发起付费调用。检查和建议不自动修改成片。


### 审片视频加载失败后继续观看

在播放器的“播放异常？”中点击“重新载入视频”。载入失败或超时可以再次重试；恢复后停在重载前的位置，并保留倍速、音量与静音设置，点击播放继续。已有观看记录保留，重载不会代为完成审片确认。若提示旧版本文件缺失或完整性异常，请返回当前成片或按提示处理文件，反复重载不能恢复缺失文件。
