# CUTROOM 多模型与供应商配置

CUTROOM 先保存供应商账号，再建立“文案策划、B-roll、配音”三类配置。文案策划统一复用到文案分析、分镜规划和包装推荐；普通使用不需要安装 New API，也不需要填写渠道 ID。豆包配音使用“服务配置 + 音色目录 + 本条视频选择”：普通同事只看中文音色名称，不填写模型 ID 或音色 ID。

> 当前规则：豆包 API Key用于合成、试听和连接检测，AK/SK用于自动刷新音色目录，AppID + Access Token是旧版兼容项，可以留空。保存并检测会生成极短的测试语音。

## 添加官方直连供应商

打开“设置 → AI 服务连接 → 供应商账号”，填写：

- 供应商预设：选择接口类型，例如“火山方舟文本”。
- 供应商名称：仅用于自己识别，例如“我的火山方舟”。
- 备注：可留空。
- API Key / Access Token：填写官方控制台生成的凭据，只保存到 Windows 凭据管理器。
- API 请求地址：选择预设后自动填写，必要时可以修改。
- 默认模型：可留空；填写后，新建能力配置时会自动带出。

常见直连方式：

| 用途 | 供应商预设 | API 请求地址 | 额外字段 |
|---|---|---|---|
| 文案、分镜、包装 | 火山方舟文本 | `https://ark.cn-beijing.volces.com/api/v3`，Coding Plan 可按实际服务改为 `/api/coding/v3` | 无 |
| 缺失画面生成 | 火山方舟视频生成 | `https://ark.cn-beijing.volces.com/api/v3` | 无 |
| 豆包配音 | 豆包 TTS | 页面自动管理，不需要填写 | 豆包 API Key、Access Key ID、Secret Access Key、配音服务版本；AppID + Access Token 仅旧版兼容 |
| 其他兼容服务 | OpenAI 兼容 | 填服务商给出的完整兼容 API 地址 | 无 |

“API Key”必须来自相应官方控制台。文本和视频模型的模型 ID 或推理接入点 ID 必须按该账号实际开通情况填写；不要照抄示例名称。豆包普通流程不填写这些内部 ID。

## 豆包配音首次配置

“管理员”指拥有火山引擎主账号或相应 IAM 权限、能够创建访问密钥并查看豆包应用凭据的人；不一定是 CUTROOM 的开发人员。如果你本人管理火山账号，你就是这里的管理员。

每台同事电脑首次使用都要由管理员在该电脑录入一次，不能从 GitHub、安装 ZIP 或另一台电脑的 SQLite 自动带过来：

1. 在豆包控制台“API Key 管理”中创建或取得 **豆包 API Key**。它用于新版合成、试听和连接检测。
2. 在火山引擎“API访问密钥”页面创建或取得 **Access Key ID** 与 **Secret Access Key**。AK/SK 用于签名调用官方 `ListSpeakers` 音色目录接口。
3. 只有历史账号仍走旧版 V1 合成时，才展开“旧版兼容设置”填写 **AppID** 与 **Access Token**；新版账号留空。
4. 在 CUTROOM“设置 → AI 服务连接”添加“豆包 TTS”，填写豆包 API Key、AK/SK 并选择账号已开通的语音合成 1.0 或 2.0，然后点击“保存并检测”。
5. 检测通过并刷新目录后，新建配音配置，从中文名称中选择常用音色。这个常用项只负责以后新广告的预选，不会强制所有视频使用同一个声音。

参考：[火山引擎 Access Key 管理](https://www.volcengine.com/docs/6291/65568?lang=zh)、[ListSpeakers OpenAPI](https://api.volcengine.com/api-docs/view?action=ListSpeakers&serviceCode=speech_saas_prod&version=2025-05-20)、[豆包语音控制台快速入门](https://www.volcengine.com/docs/6561/163043?lang=zh)。

豆包 API Key、Secret Access Key 与旧版 Access Token 只保存在当前 Windows 用户的凭据管理器中。Access Key ID、旧版 AppID、服务版本和已缓存音色元数据保存在本机 SQLite；GitHub、发布 ZIP、任务快照和复制出的 SQLite 都不含密钥。换电脑后，管理员必须在新电脑重新录入所需凭据；配置完成后，同事在该电脑的 CUTROOM 中可以直接选音色和制作视频。

## 添加三类模型配置

供应商保存后，在相应能力卡片中填写：

- 供应商账号
- 配置名称
- 文案策划和 B-roll 的精确模型 ID
- 豆包配音的常用音色（按中文名称选择）

一个供应商账号可以被多个配置复用。文案策划负责文案分析、分镜和包装推荐；B-roll 只在本地素材缺口时生成画面；配音只用于信息流广告 TTS。同一类可以添加多个模型、分别测试，并设置其中一个为默认项。

支持模型目录的供应商可以点击“获取模型”；豆包配音点击“获取/刷新音色”。只有“New API（高级兼容）”等没有标准音色目录的高级入口保留手工音色配置，普通豆包流程不会显示音色 ID 输入框。

## 测试和任务调用

添加模型后必须点击“测试连接”：

- 文本模型会发起一次极小的真实对话请求。
- TTS 会生成一段极短测试音频。
- 视频生成只检查模型目录，不会在测试时产生付费视频。

只有 24 小时内测试通过的配置才可用于新任务。任务创建后会冻结供应商、API 请求地址、模型、协议、音色和高级参数；API Key 不进入任务账本。实际执行始终使用冻结的指定配置，失败时直接提示，不静默换模型。

数字人混剪必须选择“文案策划”，B-roll 按需选择；它使用原视频声音，不显示配音和音色字段。信息流广告必须选择“文案策划”和“配音服务”，B-roll 按需选择；随后必须在始终可见的“本条视频音色”下拉框中明确选择。页面可以预选常用音色，但允许改成目录中的其他声音。创建后会冻结本条视频实际选择的音色，后来修改常用项或刷新目录都不会改变旧任务。

## 豆包音色故障排查

| 页面提示 | 怎样处理 |
|---|---|
| 缺少 AK / SK | 点击该豆包账号的“补充/更新凭据”，填写 Access Key ID 和 Secret Access Key；两项必须属于同一个有权限的火山身份。 |
| `ListSpeakers` 无权限或鉴权失败 | 请火山主账号/IAM 管理员确认 Access Key 未禁用，并给该身份开通 `speech_saas_prod` 音色列表所需权限；不要反复改填 AppID，因为目录鉴权使用的是 AK/SK。 |
| 缺少配音服务版本 | 在账号凭据区选择已开通的豆包语音合成 1.0 或 2.0，再保存并刷新。 |
| 刷新成功但目录为空 | 核对服务版本和账号开通范围；页面不会伪造音色，也不会静默使用内置默认声音。 |
| 试听失败 | 保留当前选择，优先检查豆包 API Key、服务版本与音色授权；仅旧版账号再检查 AppID/Access Token。试听失败不会被记录成检测成功。 |
| 刷新失败但以前有音色 | 上一次成功目录会保留；先按页面错误修复再刷新。已创建任务仍使用冻结音色。 |

## 可选：New API

只有确实需要本机统一网关或多渠道路由时，才选择“New API（高级兼容）”：

- API Key 字段填写 New API 令牌。
- API 请求地址通常为 `http://127.0.0.1:3000`。
- 选择 New API 预设后页面直接显示固定渠道 ID，可以留空。
- 留空时由 New API 根据令牌和模型自行路由；填写后任务固定使用该渠道。

现有 New API 账号和旧任务继续兼容，不需要重新配置。New API 使用 AGPLv3；若以后修改 New API 本身或向外部提供该服务，再单独复核对应许可义务。
